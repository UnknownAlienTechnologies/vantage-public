# Vantage — public pages

The support page and privacy policy for [Vantage](https://apps.apple.com/app/vantage), an iOS app
that turns a spare iPhone into an ONVIF/RTSP security camera for network video recorders.

Published with GitHub Pages:

- Support: <https://unknownalientechnologies.github.io/vantage-public/>
- Privacy policy: <https://unknownalientechnologies.github.io/vantage-public/privacy>

This repository contains only these two documents. The app's source is not public.
